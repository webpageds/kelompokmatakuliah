# Academic Curriculum Center

Sistem manajemen kurikulum Program Studi Akuntansi.

Modul yang direncanakan: Dashboard, Kelompok Bidang Keahlian, Kelompok Mata Kuliah, dan RPS Development.

Empat KBK: Keuangan, Manajemen, Pajak, dan Audit. Mata kuliah berkode KBK ALL diperlakukan sebagai mata kuliah lintas bidang.

Data awal mengacu pada MAPPING KMK PRODI AKUNTANSI.xlsx.

## Catatan versi
Aplikasi web akan dimulai sebagai prototipe static. Data pada prototipe lokal tersimpan di localStorage browser dan belum tersinkron antar pengguna. Untuk penggunaan resmi diperlukan backend/database, autentikasi berbasis peran, audit log, dan penyimpanan dokumen RPS terpusat.
